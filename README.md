# LLM Post-training Learning Lab

从已有的 Transformers SFT 经验出发，学习自造数据、工具使用、偏好学习、单轮/多轮 RL 和知识/Skill 内化。Codex 担任老师、提问者与代码审阅者。

**这是学习规范包，不是可直接运行的训练仓库。** 训练代码由你在每章逐步实现；包内没有虚构的实验结果，也没有提前完成你的作业。

## 先看哪些文件

| 文件 | 用途 |
|---|---|
| [LEARNING_PLAN.md](LEARNING_PLAN.md) | 主课程：各阶段资料链接、阅读范围、目标、作业、验收与踩坑检查 |
| [AGENTS.md](AGENTS.md) | Codex 项目教学规则：提示优先、一次一题、先审再改、真实证据与预算 |
| [PROGRESS.md](PROGRESS.md) | 当前章节、环境、薄弱点、实验状态、下一步；每次学习后更新 |

| [实验模板](templates/EXPERIMENT_TEMPLATE.md) | 配置、实际命令、数据、成本、结果与失败分析 |

不需要一次读完主文档。先读“先读这一页”和 C00，再由 Codex 按进度安排。

## 启动

1. 把本包解压到你准备的 `llm-posttraining-lab/`。文件应直接位于该目录根部，避免误放成两层同名目录。已有同名规则先合并，不覆盖。
2. 在该目录启动 Codex。让它先读取本包的规则、主计划和进度；不要直接说“帮我实现全部项目”。
3. 发下面这段：

```text
请读取 AGENTS.md、LEARNING_PLAN.md、PROGRESS.md，按本仓库规则当我的老师。
我有过去用 Transformers Trainer 做 SFT 的经验，本机是 RTX 5070 Ti 16GB。
今天只开始 C00，不一次性生成整个项目。
先确认生效的教学规则和当前工作目录，再问我 1～2 个诊断问题。
随后做只读环境检查，给我最多两个阅读入口、明确范围和一个最小作业。
我读完后请一次一题考我；代码由我先写，你先审查，不默认代写或修改核心逻辑。
未获授权，不安装大批依赖、下载模型、调用付费 API 或启动 GPU 训练。
结束时更新 PROGRESS.md，留下下一次唯一任务。
```

当前这台 WSL2 机器已经建立 D 盘项目环境。进入正式仓库后可执行：

```bash
cd /mnt/d/llm-posttraining-lab
source scripts/env.sh
```

实际版本、模型 revision 和 smoke test 证据见 `reports/environment.md` 与 `reports/model_selection_and_memory.md`。该入口只激活环境，不会自动下载模型或启动训练。

## 主路线

| 章节 | 主要产出 |
|---|---|
| C00 | 知识地图、环境报告、最小模型试跑 |
| C01 | 虚构任务、真实工具、独立 verifier、评测基线 |
| C02 | 可追踪、可过滤、可重放的小规模合成数据 |
| C03 | Tool-use SFT、token/mask 检查、保存重载与 dev 对照 |
| C04 | 可信偏好样本、DPO 理解与可选训练 |
| C05 | 自写数学练习、真实单轮 GRPO 更新与诊断 |
| C06 | 多轮 rollout、真实 Agentic RL 更新、verl 映射 |
| C07 | 知识/Skill 对照、学生失败修复 SFT |
| C08 | 封存集评测、复现报告、代码答辩 |

建议预算约 6～8 周、60～90 小时；这是学习安排，不是完成保证。按验收推进；卡住就记录阻塞，不能用“看完视频”代替实训。

## 每次怎样学

**少量阅读 → 自己解释 → 自己编码 → Codex 提问 → Codex 审查 → 自己修复 → 记录进度。**

开始：`读取进度，先复查一个薄弱点，今天只安排一个学习目标。`

读完：`按本章要求考我，一次一道题，等我作答后反馈，不提前给答案。`

代码写完：`先按验收标准审查我的代码与测试，报告文件行号、影响和最小复现；暂时不要替我修改。`

结束：`分别记录掌握状态、实际执行程度、效果证据，再给出下一次唯一任务。`

## 先达成这个里程碑

你能解释一条工具任务如何变成 token 和 loss，并留下：**可复现环境、独立验证器、真实评测过的 Tool-use SFT 基线。** 然后再进入 RL。

## 资料与限制

主计划包含官方课程、TRL/Transformers/PEFT/verl 文档、四篇主论文，以及五道口纳什的选看入口。链接核验时间及 B 站访问限制在主文档中说明；网页、版本与视频可用性之后仍可能变化。

不要把 API 密钥放入仓库或聊天记录；先 mock，再小批量验证，最后才扩大付费生成。学习者提供“能够调用 API”的背景，不等于授权无限额调用。
